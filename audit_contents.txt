BLOCK 3: Rule-Based Warning Scores (No Model File)
Build a transparent rule engine for RISK RADAR using yfinance .NS data only.
Rules (explicit if/elif, no black box):
- Price drop >5% in 5 days → score +20
- Price drop >10% → score +40
- Volume >2× 20-day avg → score +15
- Volume >3× → score +30
- Stock >40% below 52W high → score +20
Cap at 100. Show flags array explaining each score contribution.

BLOCK 4: Render Free Tier Constraints
Every feature must pass:
1. RAM < 512MB — no model files >400MB
2. PORT env var — never hardcode port
3. No persistent disk — cache = in-process Python dict
4. No background workers — use asyncio tasks in FastAPI lifespan
5. Never call yf.download() per-request — batch only in sync loop
6. Cold start after 15min — /health must return in <1s
USE WHEN: Before implementing any new feature. This is a hard constraint list, not a guideline.

BLOCK 5: NSE IP Block — Hard Limit
NSE hard-blocks Render/cloud IPs.
DO NOT attempt: nsetools, nse-india-data-api, api.nseindia.com direct calls.
DO use:
- yfinance .NS tickers (works from cloud)
- Static fallback JSON files in /public/data/ (commit real snapshots weekly)
- Accept that options chain (PCR, OI) is not available on free tier
Build warning system around yfinance proxies only.
USE WHEN: Any suggestion to use NSE directly. This is an architectural constraint, permanently.

PATCH 3: Rule-Based Danger Score
def compute_rule_based_danger(symbol: str, df_stock) -> dict:
    closes = df_stock["Close"].dropna()
    volumes = df_stock["Volume"].dropna()
    if len(closes) < 5:
        return {"danger_score": 0, "flags": []}
    price_drop = (closes.iloc[-1] - closes.iloc[-5]) / closes.iloc[-5] * 100
    vol_ratio = volumes.iloc[-1] / volumes.iloc[-5:].mean()
    score, flags = 0, []
    if price_drop < -10: score += 40; flags.append(f"Drop {price_drop:.1f}% in 5d")
    elif price_drop < -5: score += 20; flags.append(f"Drop {price_drop:.1f}% in 5d")
    if vol_ratio > 3: score += 30; flags.append(f"Volume {vol_ratio:.1f}× avg")
    elif vol_ratio > 2: score += 15; flags.append(f"Volume {vol_ratio:.1f}× avg")
    pct_from_high = (closes.iloc[-1] - closes.max()) / closes.max() * 100
    if pct_from_high < -40: score += 20; flags.append(f"{pct_from_high:.1f}% from 52W high")
    return {"danger_score": min(score, 100), "flags": flags}
